# SmartUniLab 🎓

**SmartUniLab** is a university project designed to provide a smart platform for managing university lab-related activities.

## 🛠️ Technologies Used

- **Frontend:** React, Vite
- **Backend:** Java, Spring Boot
- **Database:** MariaDB

## 🗄️ My Contribution – Database Design & Development

I was responsible for the database part of the project, including:

- Designing and creating the database.
- Creating the required tables and defining their structures.
- Establishing relationships between tables.
- Writing and executing SQL queries.
- Organizing the database to support the application's functionality.

**Database Management System:** MariaDB  
**Database Name:** `smartunilabdb`

## 🏗️ Project Architecture

The project follows a full-stack architecture:

- React handles the user interface.
- Spring Boot handles backend operations and application logic.
- MariaDB stores and manages application data.

## 📌 What I Learned

Through this project, I gained practical experience in:

- Relational database design.
- SQL query writing.
- Database relationships and data organization.
- Understanding how databases integrate with backend applications.
